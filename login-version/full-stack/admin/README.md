# 任务分发管理后台

管理员登录后进入 `/task-management`。工作台展示实际任务数、团队成员数和待审核提现数。菜单和操作由后台账号的角色权限决定。

| 入口 | 管理内容 |
| --- | --- |
| 任务与评论池 | 关联媒体账号、作品链接、评论池、分发范围和每单金额；保存草稿、正式发布、复制 H5 链接、暂停或关闭；导入和导出 Excel |
| 订单审核与结算 | 按任务查看成员执行记录和证明图片，填写实际结算金额，或填写原因并驳回补交 |
| 团队与团长、H5 成员 | 成员邀请与绑定、团长申请和分佣记录、成员账号与限制 |
| 奖励提现 | 审核成员提现申请，按服务端的提现模式查看和同步打款结果 |
| 媒体账号、账号与组织 | 配置发布任务使用的媒体账号、租户、管理员账号和权限 |

创建任务前先配置本租户可用的媒体账号。正式发布会在服务端校验评论池数量和账号状态；发布成功后可在任务列表重新复制派发链接。订单结算会写入成员钱包，实际微信转账需另外完成成员提现及商户侧授权配置。

## 本机运行

先启动本版后端、数据库与 Redis，初始化租户和管理员。复制 `.env.example` 为 `.env.development`。默认管理端地址为 http://127.0.0.1:8781 ，后端为 http://127.0.0.1:8783 ，成员端为 http://127.0.0.1:8782 。使用 Node.js 22 和 pnpm 9.15.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

使用部署者创建的管理员账号登录。一个账号拥有多个租户时，需要先选择租户。

## 生产发布

复制 `.env.example` 为 `.env.production`。填写 `VITE_API_BASE_URL` 作为浏览器接口前缀，`VITE_DISPATCH_BASE_URL` 作为成员能打开的 HTTPS 任务站点。独立文件域名可填 `VITE_ASSET_BASE_URL`。这些地址会写入静态网页，公众号 AppSecret、短信密钥、商户私钥等配置只填在后端。运行 `pnpm build` 完成类型检查和构建，将 `dist/` 部署为静态站点，前端路由回退到 `index.html`，按部署方案反向代理同源 `/api/` 和后端的本地公开资源路径。重新配置前端地址后需要重新构建。

完整的材料清单也可以在管理台或登录页的[部署准备清单](public/deployment.html)中查看。本目录沿用[非商业许可](LICENSE)与[署名](NOTICE)。
