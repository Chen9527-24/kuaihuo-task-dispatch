部署准备

先跑通任务和钱包记账，再按实际业务接入微信登录、短信和资金发放。

在本机体验

准备一台装有 Docker Engine、Compose v2 和 Python 3.9+ 的电脑。进入登录版目录运行 python3 run.py（Windows 可用 py -3 run.py）。首次联网下载镜像和依赖，生成私有配置与管理员账号。通过模拟短信可以体验成员登录、领取、交证明、审核和钱包入账。

公开部署需要准备什么

服务器、域名与图片存储

准备能长期运行的服务器、PostgreSQL 16、Redis 7、DNS 管理权限和 HTTPS 证书。可将同一域名的两个子域分别指向管理后台和成员 H5。在中国内地托管并使用域名对外服务，向服务器接入商办理适用备案。成员截图请放私有存储桶，使用经过鉴权的短时访问地址。

备案适用范围

成员通过短信验证手机号

当前对接腾讯云短信。准备短信应用 SDKAppID、审核通过的签名和验证码模板 ID、相应的实名资质、发送额度与服务端密钥。后台驳回或结算短信属于另外的通知模板，可按需启用。正式环境使用 SMS_PROVIDER=tencent。

腾讯云验证码接入

微信内授权、打开任务与分享

准备具备网页授权权限的公众号、AppID 和 AppSecret。配置网页授权域名、回跳白名单及所需的 JS 接口安全域名、服务器 IP 白名单。H5 的微信内授权用于取得本公众号下的用户标识 openid；业务要求绑定手机号时仍按提示完成短信验证。仅本机体验手机号登录时可关闭微信授权。

公众号网页授权

微信商户真实发放奖励

准备有资格的商户号，开通「商家转账」，按实际用途报备场景，关联具体 AppID，配置资金、限额和接口 IP。后端还需商户证书序列号、商户私钥、APIv3 密钥、微信支付验签公钥和公钥 ID，以及外网可达的 HTTPS 回调。商户号或公众号单独一个都不足以完成转账。

商家转账开通条件 · 用户确认收款与查单

奖励怎么到成员手上

  1. 审核人员核对截图，确认实际结算金额，系统把金额记入成员的钱包。
  2. 成员在手机微信内申请提现，由发布方审核。正式模式会向微信支付发起商家转账；需要用户确认时，成员按页面提示确认收款。
  3. 服务端接收并核验微信支付回调，或用原商户单号查单，再更新到账、失败或退款状态。核对业务流水和商户账单后完成验收。

在源码包的 full-stack/docs/DEPLOYMENT.md 查看启动、路径和验收步骤，full-stack/docs/INTEGRATIONS.md 包含各项配置字段。真实密钥和证书只存放在自己的服务端。
