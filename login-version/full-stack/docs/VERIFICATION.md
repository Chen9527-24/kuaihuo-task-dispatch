# 登录完整版验证记录

2026 年 11 月 25 日，在 macOS 本机运行独立的管理后台、成员 H5、任务 API、PostgreSQL 16 和 Redis 7。验证使用专门新建的数据库及虚构成员，不需要原五项目或原业务数据。

| 范围 | 实际操作与结果 |
| --- | --- |
| 源码与初始化 | 从干净目录按各自的 pnpm 锁文件安装并构建三个应用。对空数据库执行两步迁移、建立管理员和业务租户；保留同一数据库重复执行初始化，已有账号和数据可以继续使用。 |
| 管理员发布 | 在浏览器登录、选择业务租户，打开任务工作台及 11 个管理页面。创建一条有作品和评论的任务，在发布确认框执行发布。服务端写入派发状态和时间，生成的链接带上该任务和租户。 |
| 成员领取与交付 | 在手机尺寸的 Chrome 中从分享链接进入，走模拟短信登录、邀请码入组、回到指定任务、领视频与评论、上传主页图和执行证明并提交。后台能打开提交的凭证。未发布任务无法领取，缺少主页图时无法提交。 |
| 审核与钱包 | 后台已结算记录和待审核记录显示相应的操作，待审核样例正确显示 2.50 元。本机另对一张 1.50 元订单发出四次并行结算请求，钱包只增加一次，流水只有一笔。 |
| 支付回调处理 | 使用本机生成的临时测试密钥，检查通知签名、公钥 ID、时间戳和加密通知内容。错误签名和错误公钥 ID 被拒绝，正确样例可以验签解密。 |
| 源码分享 | 登录版独立包含说明、启动入口、配置模板、初始迁移、两张人工制作的示例图片和非商业许可。后台体验账号、数据库、上传记录及证书随部署各自生成和保存。 |

**运行方式。** 这次实际联调运行的是原生服务。本机已校验整套 Compose 配置、初始化程序和静态站点构建。每次发布还会在全新的 Ubuntu 环境启动容器，检查管理员登录、任务列表、H5 和服务连通性。对应提交的结果可在 [GitHub 安装验证](https://github.com/Chen9527-24/kuaihuo-task-dispatch/actions/workflows/check.yml) 的 full-login 一项查看。

**正式接入。** 本次没有发送真实短信、在手机微信中授权或调用商户转账。公网域名和 HTTPS、微信登录和分享、真实短信、私有存储的授权与签名过期、微信零钱到账和商户对账，应由部署者使用自己的账户、资质与设备逐项验收。[正式接入与验收步骤](INTEGRATIONS.md)
