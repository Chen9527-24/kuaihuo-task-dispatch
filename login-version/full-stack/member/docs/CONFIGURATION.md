# H5 配置说明

只需从 `.env.example` 创建自己的环境文件，填写部署地址与租户。浏览器端 `VITE_*` 都是公开值，不能保存密码、Token、公众号 secret、云服务或模型密钥。

## 变量

| 变量 | 安全默认/填写要求 | 作用 |
| --- | --- | --- |
| `VITE_APP_ENV` | `development`；正式使用改 `production` | 控制短信模拟码等界面分支，不决定后端是否真正发送短信 |
| `VITE_API_BASE_URL` | `/api/v1` | 业务请求前缀 |
| `VITE_API_PROXY_TARGET` | `http://127.0.0.1:3000` | 本地 Vite `/api` 和 `/uploads` 代理目标，生产需自己配置反向代理 |
| `VITE_DEFAULT_TENANTS_ID` | 空，填写后端初始化的业务租户 ID 或租户代码 | 未登录且未配置时显示配置提示，不向原租户发请求 |
| `VITE_ENABLE_WECHAT_OAUTH` | `false` | 开启时要求自己的微信服务号网页授权配置 |
| `VITE_WECHAT_OAUTH_API_BASE_URL` | 空，回退到 API 地址 | 后端 OAuth 入口地址 |
| `VITE_WECHAT_OAUTH_RETURN_ORIGIN` | `auto` | 本地开发回跳来源；后端仍需允许该来源 |
| `VITE_WECHAT_SHARE_IMAGE_URL` | 空；可填有权使用的公开 HTTPS 图片完整 URL | 自定义微信分享图；空时不设置，不加载旧业务分享图 |

本地执行 `cp .env.example .env.development`；生产构建另建 `.env.production`。这些变量在构建时生效，运行时修改服务端环境不会自动改变已有静态包。

## 部署后配置租户和微信入口

页面载入时会先读取站点根目录的 `runtime-config.js`。使用整套部署时由启动流程生成；单独发布静态文件时，也可编辑 `dist/runtime-config.js`。示例中的租户标识应换成实际值。

```js
window.__TASK_CONFIG__ = {
  tenantId: "填写自己的租户标识",
  wechatOAuth: false
}
```

这两个字段分别优先于 `VITE_DEFAULT_TENANTS_ID` 和 `VITE_ENABLE_WECHAT_OAUTH`。其余前端字段仍在构建时写入。更新文件后刷新浏览器即可；反向代理对 `runtime-config.js` 应关闭长时间缓存。所有值均对访客公开。

## 租户与登录

没有内置业务租户。旧公开任务链接如显式带 `tenantId` 或 `tenantsId`，会在当前浏览器会话保留该选择，避免转到登录页后丢失。同一标签页沿用选定的租户；新标签页的普通入口使用配置的默认租户；已登录令牌可以继续由后端识别所属身份。租户参数只用于现有接口兼容，真正的租户授权必须由后端验证。

后台按任务生成的分享链接包含 `taskId`。新成员完成登录和团队绑定后，页面会展示该团队范围内的对应任务；可选择「查看全部任务」回到任务大厅。

手机号登录要求部署者配置后端短信通道或明确的开发模拟模式。前端不会生成可绕过后端校验的验证码。未配置站点租户时，请由管理员填写环境文件并重新启动/构建。

## 微信与付款

默认关闭 OAuth，先在普通浏览器验证自己的业务。开启后需要自有公众号、网页授权域名、回调允许来源和后端配置；微信分享另需 JS 接口安全域名、后端签名接口及公开可访问的自有图片。原公众号验证文件已移出，部署者按自己的公众号配置提供文件。

提现页面只提交申请、显示后端状态并在支持的微信环境发起收款确认。实际商户、付款能力和资金结果由后端配置及支付服务决定，不附带真实商户账户。

## 生产部署

静态站点路由需回退到 `index.html`，`/api` 和 `/uploads` 需代理到本项目后端。分别配置测试和生产租户，不复用真实成员数据制作公开示例。当前任务流程保留旧接口，分发 V2 不在此版本中。

## 图片和调试

平台截图替换为写明“非平台截图”的通用操作示意。可由部署者自行制作并替换为有权发布的材料。调试面板只通过 `h5Debug` 查询参数启用，日志虽遮蔽令牌字段，仍可能包含用户业务资料，请勿公开真实调试导出。

## 操作弹窗的教学图

登录版保留「打开作品」和「领取评论」操作弹窗，弹窗内的教学图可以点击放大。源码包自带一张通用操作示意。要使用自己的平台教学图，只需准备图片并配置地址。

独立发布 H5 时，把有权公开的教学图片放在站点根目录的 `task-guides/` 中。在 `runtime-config.js` 已有的 `tenantId`、`wechatOAuth` 配置后添加 `guideImages`。示例也可以直接追加在现有配置之后。

```js
window.__TASK_CONFIG__.guideImages = {
  douyin: {
    start: {
      ios: '/task-guides/open-video-ios.png',
      android: '/task-guides/open-video-android.jpg'
    },
    claim: '/task-guides/copy-comment.png'
  }
}
```

- 平台名使用 `douyin`、`xiaohongshu`、`weixin`。两阶段分别用 `start` 和 `claim`。每个阶段可写一张通用图的地址，也可按 `ios` 和 `android` 分别填写。桌面预览使用 Android 配置，与原成员端的判断一致。微信视频号采用自己的打开作品及复制提示流程，图片配置不会改变这些步骤。
- 抖音的打开作品和领取评论各用自己的图。小红书及视频号未单独配置评论图时沿用该平台的打开作品图。缺少对应配置、地址无效或图片加载失败时，弹窗和点击放大均使用随包的通用图。
- 图片地址可使用以 `/` 开头的本站路径，或部署者自有的完整 HTTPS 图片地址。图片会供成员直接查看，应使用获授权、已去除个人信息的素材。修改配置后刷新 H5 生效。
