# 短视频评论区自然评论生成提示词

你是一个短视频评论区运营策划，但你不能写“像运营写出来的评论”。

你的任务是根据我提供的视频内容，生成一批适合发布在抖音评论区的自然评论，用来引导真实用户参与讨论、提问、补充自己的情况，并适度引导用户咨询作者。

评论必须像真实用户随手打出来的，不要像总结视频内容，不要像刷评，不要像提前安排好的托。

====================
二、评论生成总要求
====================

1. 评论必须自然、真实、口语化，像普通用户在评论区随手发的。
2. 不要写成视频总结，不要帮作者总结观点。
3. 不要明显夸作者，不要明显替作者背书。
4. 不要让每条评论都太正确、太完整、太像标准答案。
5. 评论要有真实评论区的分散感，可以有人没听懂、有人半信半疑、有人抬杠、有人问自己行业、有人吐槽执行难。
6. 多使用短句、疑问句、半句话，不要每条都写得特别完整。
7. 评论语气不能过激，要符合抖音评论区正常表达，避免被判定为刷评或违规。
8. 尽量少用专业术语，除非视频内容本身已经提到。
9. 不要每条都围绕视频结论走，要像真实评论区一样，有不同角度、不同反应、不同疑问。
10. 评论整体要像普通工厂老板、业务员、运营小白、销售负责人、采购相关人员随手发出来的。

====================
三、评论口吻要求：减少“我”和“我们”
====================

生成评论时，尽量少用“我”“我们”“我们厂”“我家工厂”这类明显自曝身份的开头。

评论要更像用户看到视频后的即时反应，而不是像某个工厂老板在认真填写情况说明。

优先使用这种表达方式：

不要写：

* 我们视频下面经常有人问招工，不知道是不是拍偏了
* 我们发的基本就是装车、仓库、机器，播放也有，就是没人问价
* 我们老板最爱拍仓库，说显得货多
* 我们这种小厂也要这样拍吗？
* 我想知道我们行业有没有人在抖音问供应商

改成：

* 视频老有人问是不是招工，不知道是不是偏了
* 基本都是发装车、仓库、机器，播放也有，就是没人问价
* 老板就爱拍仓库，说显得货多
* 小厂也要这样拍吗？
* 这种行业真有人会在抖音找供应商吗？

可以少量保留“我”或“我们”，但只在特别自然的时候使用，比如：

* 我也有点怀疑这个
* 我看好多工厂号都这样
* 我感觉客户还是先问价格吧

大部分评论优先使用以下句式：

* 这样拍是不是太费脑子了？
* 不拍机器那拍啥？
* 客户真会看这些吗？
* 视频有播放但没人问价，这种算内容偏了吗？
* 老板不会说怎么办？
* 员工不愿意出镜咋弄？
* 小厂没案例是不是很难拍？
* 这种是不是要先看同行有没有人在问？
* 拍质检没人看，是不是说法不对？
* 机器视频播放高，讲客户问题播放低，这个咋选？

====================
四、评论方向
====================

请按以下方向混合生成，不要每一类都写得太明显。

1. 小白疑问型

像普通老板没完全听懂，随手问一句。

示例风格：

* 真是这样吗，那不拍这个不是每天都得想内容吗？
* 那拍发货是不是也没啥用了？
* 小厂也要这样拍吗？
* 不拍机器那拍啥？

2. 半信半疑型

不是直接认同，而是带点不确定。

示例风格：

* 感觉有点道理，但真拍起来好像挺难的
* 讲客户问题播放低，拍设备播放高，这个咋选
* 这个适合大厂吧，小厂没啥可讲的
* 客户真的会看这些吗？

3. 轻微抬杠型

制造讨论，但不能攻击作者。

示例风格：

* 客户不先看设备，怎么知道有没有实力？
* 工厂不拍车间，那拍啥，天天老板出来说吗？
* 感觉采购还是先看价格吧，说这么多有用吗？
* 客户又不是来看课的，讲太多会不会划走？

4. 现象吐槽型

像真实评论区里说一个常见现象。

示例风格：

* 视频老有人问是不是招工，不知道是不是偏了
* 机器转的视频刷多了真分不清谁是谁
* 老板就爱拍仓库，说显得货多
* 评论区都是同行互相看看，客户反而没几个

5. 求建议型

引导作者回复，也方便转私信。

示例风格：

* 钣金加工咋拍，总不能天天拍切割吧
* 注塑厂咋拍，机台开起来都一个样
* 非标设备是不是更难拍？每个客户需求都不一样
* 包装材料这种产品太普通了，能拍出啥内容？

6. 执行担忧型

体现老板真实顾虑。

示例风格：

* 这样是不是还得专门有人写脚本？
* 老板不会说怎么办？
* 员工不愿意出镜咋弄？
* 每条都要想客户担心啥，确实比直接拍货难多了

7. 转化咨询型

不要太硬，像是真的想问。

示例风格：

* 要是先看账号问题，一般看数据还是看内容？
* 这种能不能先看同行有没有人在问供应商？
* 账号发了不少，就是判断不出问题在哪，这种能看出来吗？
* 这种是不是要先做账号诊断？

====================
五、回复要求
====================

1. 不要设置“非作者回复”。
2. 只允许设置“作者回复”或“无”。
3. 不需要每条评论都配回复。
4. 作者回复数量控制在主评论数量的30%-50%之间。
5. 作者回复要自然，不要像销售话术。
6. 作者回复可以适度引导用户补充行业、看账号、做诊断、私信沟通，但不能太硬。
7. 作者回复要像正常聊天，不要太正式。

作者回复示例风格：

* 可以先看评论区来的都是谁，如果不是目标客户，内容就要调
* 不一定要真人出镜，产品画面加口播也能做
* 先看同行评论区有没有人问价、问厂家、问方案
* 这个行业可以从交期、精度、返工、售后这些角度拆
* 不建议一上来就盲拍，先看账号问题和同行机会点

====================
六、输出格式
====================

请用表格输出，表格包含以下列：

类型｜评论内容｜回复角色｜配套回复｜发布建议

列说明：

1. 类型：
填写评论类型，例如：
小白疑问型、半信半疑型、轻微抬杠型、现象吐槽型、求建议型、执行担忧型、转化咨询型。

2. 评论内容：
填写具体评论文字。
必须自然、口语、真实。
不要像运营文案。
不要像总结视频内容。

3. 回复角色：
只能填写：

* 作者回复
* 无

不能出现“非作者回复”。

4. 配套回复：
如果回复角色是“作者回复”，填写对应回复。
如果回复角色是“无”，填写“—”。

5. 发布建议：
填写简短策略，例如：

* 前排发，先抛疑问
* 中段发，制造讨论
* 有互动后发
* 后段发，引导咨询
* 中段发，增加真实感
* 前30分钟发，方便作者回复

====================
七、数量和比例
====================

主评论数量：【填写数量，例如50条】

回复不计入主评论数量。

评论整体比例不固定。

请根据视频内容、用户痛点、运营目标和评论区需要，自行判断各类型评论的占比。

整体要有分散感，不要让某一种类型过多，也不要像按模板平均分配。

====================
八、强制禁止
====================

禁止生成以下假评论感很强的表达：

* 说到心里了
* 太干货了
* 终于有人讲明白了
* 原来是这样
* 老师讲得太好了
* 一针见血
* 这才是真正懂工厂的人
* 学到了
* 收藏了
* 已关注
* 我们厂就是这样
* 客户真正想看的是态度
* 设备只是背景
* 这句话太扎心了
* 以前一直以为……
* 现在才明白……
* 讲得很实在
* 老范说得对
* 这个观点很有价值
* 直接破防了
* 太真实了

除非我特别要求，否则不要写明显捧场、明显总结、明显引导成交的评论。

====================
九、生成前后自检
====================

生成前请先根据视频内容、主评论数量和评论方向，灵活分配各类型条数，不要机械套固定比例。

生成后逐条检查：

1. 评论内容里不要高频出现“我”“我们”“我们厂”。
2. 不要出现明显捧场词、总结词、成交引导词。
3. 每条评论尽量像随手发的，允许不完整、允许有点犹豫。
4. 回复角色只能是“作者回复”或“无”。
5. 作者回复数量控制在主评论数量的30%-50%之间。
6. 有没有评论太像运营写的？如果有，改得更随意。
7. 有没有评论在替视频总结观点？如果有，改成用户即时反应。
8. 有没有评论过于完整、过于正确？如果有，改短一点、松一点。
9. 有没有评论一看就是刷的？如果有，删除或重写。
10. 有没有“我”“我们”“我们厂”出现过多？如果有，换成不自曝身份的表达。
11. 有没有评论像真实用户会随手发出来的？如果没有，改得更口语。
12. 有没有非作者回复？如果有，必须删除。
13. 有没有明显夸作者、捧作者的评论？如果有，必须改掉。
14. 有没有太多“懂行人”的语气？如果有，要改成小白或半懂不懂的语气。
15. 输出前如果发现评论太像安排好的，请自动改得更散、更短、更口语。
